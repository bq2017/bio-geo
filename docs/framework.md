# 项目框架

## 项目边界

项目分为三个逻辑部分：

1. 代码项目：源码、测试、配置模板和规范文档，提交至 Git。
2. 数据项目：原始数据、中间数据、标注数据和最终数据，仅保存在本地。
3. 运行结果项目：打标输出、评测结果、质量报告和日志，仅保存在本地。

## 数据流

```text
原始题目 → 清洗与结构化 → 人工或自动打标 → 质量校验 → 标准标注数据 → 评测报告
```

## 本地目录

```text
data/
├── taxonomy/       # 生物、地理知识点体系
├── raw/            # 原始数据，只读且不覆盖
├── interim/        # 清洗和转换中的数据
├── annotation/     # 待标、已标和复核数据
├── processed/      # 最终标准数据集
└── samples/        # 本地调试样例

runs/
├── tagging/        # 打标输出
├── evaluation/     # 评测结果
├── quality/        # 数据质量报告
├── reports/        # 汇总报告
└── logs/           # 运行日志
```

## 运行追溯

每次运行使用独立的 `run_id`，并至少记录：

- Git 提交哈希；
- 数据版本；
- 标签体系版本；
- 配置文件；
- 开始时间。
